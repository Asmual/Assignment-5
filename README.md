## 1️⃣ What is the difference between var, let, and const?
### ✔Answer to Q-1:
- In JavaScript, var is the old method for creating variables. It can be declared multiple times and its value can be changed.
- let is a modern way to create variables. Its value can be changed, but it cannot be declared again with the same name.
- Const is a variable whose value cannot be changed, and It cannot be declared with the same name.

## 2️⃣ What is the spread operator (...)?
### ✔Answer to Q-2: 
- The spread operator is an operator that allows to use all the values in an array or object separately keeping them together.
It can easily combine arrays, copy objects, and pass multiple values.

## 3️⃣ What is the difference between map(), filter(), and forEach()?
### ✔Answer to Q-3: 
- map(): Goes through each item and creates a new array with modified values.
- filter(): Goes through each item and creates a new array with only the items that match a condition.
- forEach(): Used to go through each item in an array and perform an action. It does not create a new array.


## 4️⃣ What is an arrow function?
### ✔Answer to Q-4: 
- An arrow function is a shorter and simpler way to write functions in JavaScript. It makes the code cleaner and easier to read.

## 5️⃣ What are template literals?
### ✔Answer to Q-5: 
- Template literals are a way to write strings using backticks. They allow you to easily include variables or expressions inside a string.
